# Virajp Tap

## How do I install these formulae?

`brew install virajp/tap/<formula>`

Or `brew tap virajp/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "virajp/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
